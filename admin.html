Aubergine admin

Owner access only. Signing in needs the owner's GitHub access key, so nobody else can change the website.

How do I get the access key?
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under Repository access choose Only select repositories and pick just this website's repository.
  3. Under Permissions → Repository permissions set Contents to Read and write. Nothing else.
  4. Set an expiry date, generate, and copy the key. Paste it here. It is kept only while this tab is open and is never stored on the website.
